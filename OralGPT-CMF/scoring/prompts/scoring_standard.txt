# AI评分标准 v2.1 精简版（2026-10-20）
# 按当前问题与参考的临床语义评分，接受同义概括和部分正确内容；不按篇幅、格式或逐字一致评分。
# 同一错误只在主要所属维度扣分；无相关要求才可N/A，漏答不能N/A。题分按适用满分归一，综合分仍为三类等权平均。
# 数量允许合理视觉估测误差，不设固定毫米容差；方向、对象和主要类别必须一致。
categories:
  perception:
    label: 模态感知
    tasks: [FACE, FRONTAL_FACE, LATERAL_FACE, IO, CEPH, CT, PANO]
    criteria:
      factual_agreement:
        label: 事实内容一致性
        max_score: 40
        description: >-
          状态、方向和主要类别与参考一致。允许主观视觉估测中合理的小幅数值差异，不要求数值完全相等，也不设固定毫米容差。
          差异不影响主要形态判断时从宽接受；明显改变异常程度或结论时扣对应分。定性判断正确且本题未要求具体数值时，不因省略数值扣分。
          先核对对象、参照、状态、单位及符号的临床含义，不能仅凭数字接近判为一致。
      entity_binding:
        label: 牙位与空间关系
        max_score: 25
        description: >-
          患者左右、前后、上下、上下颌、解剖对象及牙位—状态绑定正确；骨／软组织、静态／动态分别核对。
          数量近似不能豁免方向写反、牙位错绑或将明确偏斜写成居中。方向错误主要在本维度扣分，不重复处罚同一事件。
      coverage:
        label: 核心发现覆盖
        max_score: 25
        description: >-
          覆盖本题核心异常和影响判断的重要发现；允许简洁概括，不强求全部测量、正常描述或逐项阴性栏目。
          非必需数值省略不算遗漏，部分覆盖给部分分；已扣分的相反断言不再作为同一事实遗漏重复扣分。
      certainty:
        label: 否定与不确定性
        max_score: 10
        description: >-
          保留影响结论的否定、疑似和限定，不将疑似升级确诊或明确病变改为不存在。
          无实质含义变化的措辞从宽；参考未记载但不冲突的新增内容标待核实，不直接判为错误。
  diagnosis:
    label: 诊断
    tasks: [DIAG]
    criteria:
      core_diagnosis:
        label: 核心诊断方向
        max_score: 60
        description: >-
          主诊断及核心方向正确，本维度应给高分；接受等价术语，不因次要遗漏回扣核心分。部分正确给部分分。
          主要骨性分类、垂直模式或前后方向明确相反时明显扣分，不靠篇幅补回；同一错分不在其他维度重复重扣。
      diagnostic_detail:
        label: 关键分型与部位
        max_score: 20
        description: >-
          关键对象、部位、侧别及分型正确。轻微程度措辞、次要修饰或非核心细节遗漏从宽；实质方向或对象错误仍扣分。
      reference_reasoning:
        label: 必要依据与综合关系
        max_score: 5
        description: >-
          仅评本题明确要求或影响诊断含义的依据。只问诊断时，不要求复述测量及完整推理，可N/A；不自行重算或推翻临床金标准。
      coverage_uncertainty:
        label: 主要并存诊断与限定
        max_score: 15
        description: >-
          保留重要并存异常及影响判断的限定。次要遗漏轻扣，不强求正常结构、空栏目或重复描述；核心错误不重复按遗漏扣分。
  treatment:
    label: 治疗与决策
    tasks: [NECESSITY, BENEFITS, READINESS, PATHWAY, ALTERNATIVE, COMPARISON, DECISION]
    criteria:
      main_decision:
        label: 本题核心决策
        max_score: 50
        description: >-
          按当前子题评必要性、收益、可开始阶段、路径或备选比较，核心决策一致应给高分，不以完整手术方案要求每道题。
          仅缺细节不把正确主路径归零；必要与不必要、首选与不推荐、暂缓与无条件立即等主结论相反时明显扣分。
      prerequisites_sequence:
        label: 关键前置条件与时序
        max_score: 25
        description: >-
          保留本题相关的关键检查、TMJ观察／稳定、PAOO评估或必要时实施及阶段顺序；未涉及则N/A。
          允许概括和非关键细节省略，关键门槛遗漏仍扣分；明确取消条件比漏写更严重。“可开始准备”不等于“可立即手术”。
          与主决策完全相同的时机错误不再重复重扣。
      procedural_detail:
        label: 主要措施与对象
        max_score: 15
        description: >-
          主要措施及对象正确，接受等价概括；次要附加操作遗漏从宽，无具体要求则N/A。
          牙位—操作、术区和关键移动方向须正确；不将充填、根管、拔牙互换。未被参考证实但不冲突的建议不直接当作错误。
      options_uncertainty:
        label: 必需、备选与条件性
        max_score: 10
        description: >-
          保留影响选择的必需、可选、条件后执行及首选／备选关系，不要求重复每个修饰词。
          不把条件性手术或备选方案合并为全部必做；无独立要求则N/A，同一条件错误不重复处罚。
